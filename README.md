📁프로젝트 소개<dr><dr>

사용자가 원하는 음식 정보를 쉽게 찾고, 자취 환경에서 활용할 수 있는 간단한 요리 레시피와 정보를 제공하는 웹사이트입니다.<dr>

⌛개발 기간<dr>
2025년 03월 02일 ~ 20205년 03월 09일(7일)<dr>

👩🏻‍💻멤버 구성 및 역할분담<dr>
- 맹인영(Product owner): 로그인 및 회원가입 페이지 제작<dr>
- 주찬미(Scrum master): 메인 페이지 상단 및 네비게이션 바(검색창, 드롭다운, 태그 등) 제작<dr>
- 이상미(Developer): 메인 페이지 하단 및 푸터바(상세 정보, 태그 등) 제작<dr>
- 김종호(Developer): 상세 음식 페이지 제작 및 Top 버튼 구현<dr>
- 박성빈(Developer): 즐겨찾기 및 음식 카테고리 페이지 제작<dr>

🖥️개발 환경<dr>
- 개발 플랫폼: Window11
- 개발 툴: Visual Studio Code
- 웹 서버: Netlify

👩🏻‍🔧기술 스택<dr>
- Front-end: HTML/CSS/JS/bootstrap<dr>
- Etc: github, Discord

🔍주요 기능<dr>
-  로그인 및 회원 관리:  로그인, 회원가입 여부에 따른 페이지 접근 및 화면 구분 기능<dr>
- 음식 드롭다운 바 및 음식 검색: 음식 카테고리 선택을 위한 드롭다운 메뉴와 검색 인터페이스 구현<dr>
- 음식 카테고리: 음식 종류별 분류 및 추천 페이지 구현, 동적으로 변화하는 배경 효과 적용<dr>
- 음식 상세 정보: 음식별 레시피 정보, 관련 음식 및 식기 링크 제공<dr>
- 반응형 디자인: 다양한 기기에서 최적화된 사용자 경험 제공<dr>
